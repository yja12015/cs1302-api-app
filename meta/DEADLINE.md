### API 1

```
https://v2.jokeapi.dev/joke/Any?lang=en&blacklistFlags=nsfw,religious,political,racist,sexist,explicit&type=twopart&amount=10
```

> To recieve the jokes from jokes API in my application, the categories are
> used or "Any" if selected to include all of them. The "lang = en" is the
> default state for the application as it recieves the jokes in english and
> the blacklistFlags option is set into the API request so the user is unable
> to recieve any jokes that may not be SFW. The jokes recieved are set to be
> in two parts the setup and delivery as the ImgflipApi had no templates that
> could have one text alone. The amount is set to the highest amount available
> for free, 10 jokes.

### API 2

```
https://api.imgflip.com/get_memes

https://api.imgflip.com/caption_image?template_id=124055727&username=g_user_109888274588286589205&password=Secretpassword&text0=My+employer+came+running+to+me+and+said%2C+%22I+was+looking+for+you+all+day%21+Where+the+hell+have+you+been%3F%22&text1=I+replied%2C+%22Good+employees+are+hard+to+find.%22
```

> The first API link supplied the meme templates and the second supplied the
> generated meme. In the meme "/caption_image" options, the username of an
> account was required and is set to be an account I created with the site.
> The password of the account was necessary as well and in this case was a
> basic "Secretpassword." Besides this the template_id was taken from the
> "/get_memes" request and chosen by the user and the text0 and text1 are
> for the two halves taken from the JokeApi. The returned response contains
> the image link of the generated meme.

## Part 2: New

> What is something new and/or exciting that you learned from working
> on this project?

Something I learned from this project was how to interact with API in a more complex way as well as how to read and learn from provided API docs. I spent two days of the beginning of the project simply exploring different APIs and how to use them to create differnt results and how the user can be allowed to interact with them. Learning how to use API-keys (even though they were not used in this project), usernames, and passwords was a part of what I learned for using API links in RESTFUL JSON. Beyond this I learned more about javaFX objects and how to use them better as well as the certain constraints over using some of them such as the ChoiceBox being unable to be cleared easily.

## Part 3: Retrospect

> If you could start the project over from scratch, what do
> you think might do differently and why?

If I could start the project from scratch I would have better planned the UI I wanted to have initially and set that environment up before starting to create functionality in the buttons and choiceboxes. It was problematic and time-consuming to add more features I didn't realize I as I was coding as well as a better naming scheme in the variables. The longer I spent setting up the JavaFX graph the more I realized I would need to accomplish every goal and was quickly confused in my naming scheme as I added different buttons, choiceboxes, or HBoxes with different naming conventions to the point I would have to keep looking back to see which one I needed.
